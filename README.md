# Kanto Ascendant Cards

[Download Cards 1.3.1](https://github.com/Roxas2712/kasc-cards/releases/tag/v1.3.1)

Updated Red, Blue and Yellow Custom Cards use **Kanto Ascendant 6.7.16 + Voxel Ascendant 3.0.33**, pinned to the verified release ZIP checksums. Earlier Cards remain pinned to their older releases; updating the mods alone does not update a sealed Card.

| Red | Blue | Yellow |
| --- | --- | --- |
| ![Red](art/red.png) | ![Blue](art/blue.png) | ![Yellow](art/yellow.png) |

Import the new `.g1rcart` for your edition, install/update both pinned mods and fully restart the game. Card IDs, artwork, options, load order, seal and save scope are unchanged. Keep saves, mod_storage and existing optional sprite content. Cards contain launch configuration and artwork only: no ROMs or mod-code copies.

Index: https://raw.githubusercontent.com/Roxas2712/kasc-cards/main/kasc-card-index.json

The original index address in the KASC `codex/kasc-6.7-card-distribution` branch also resolves the current Cards. Existing older Card files and their previous release downloads remain available for rollback.

- [KASC 6.7.16](https://github.com/Roxas2712/kanto-ascendant/releases/tag/v6.7.16)
- [VASC 3.0.33](https://github.com/Roxas2712/voxel-ascendant/releases/tag/v3.0.33)
- [Installation auf Deutsch](INSTALLATION-DE.md)

Use your own matching ROM and a host with Custom Cards and mod-index support. Native codec, exact index resolution, save identity and compatibility checks pass on engine 0.2.61. This is not a physical mobile-device test. Ordinary non-Card saves are not automatically migrated into a Card scope.
